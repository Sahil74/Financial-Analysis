# Retail Financial Performance & Scenario Analysis

## Project Overview

This project focuses on analysing the financial performance of a retail business across its physical stores and e-commerce operations. The aim is to turn raw financial data into meaningful insights through data analysis and interactive dashboards.

The project explores monthly financial performance, compares individual store performance, and examines different business scenarios to better understand potential outcomes.

## Tools & Technologies

- **PostgreSQL** – Database management and data storage.
- **Docker** – Running PostgreSQL in a containerised environment.
- **SQL** – Data querying and preparation.
- **Visual Studio Code** – Working with SQL and project files.
- **Tableau** – Data visualisation and dashboard development.

## Dashboards

### 1. Financial Overview

Analyses the monthly financial performance of the business, focusing on:

- Revenue
- Cost of Goods Sold (COGS)
- Operating Expenses
- Operating Profit

Includes monthly comparisons, financial summaries and year-based filtering to identify changes and trends throughout the year.

**[View Financial Overview Dashboard](DS1.png)**

### 2. Store & Channel Performance

Examines performance across individual retail stores and e-commerce operations.

Key features include:

- Gross Profit, Operating Margin, Operating Profit and Revenue.
- Store-level performance comparisons.
- Physical Store vs E-commerce analysis.
- Monthly Revenue and Operating Margin trends.

**[View Store Performance Dashboard](DS2.png)**

### 3. Scenario Analysis

Compares actual financial performance against two alternative business scenarios:

- **Actual:** Recorded financial performance.
- **Best Case:** An optimistic scenario.
- **Worst Case:** A less favourable scenario.

The dashboard compares these scenarios across individual stores, helping to understand differences in potential business performance.

**[View Scenario Analysis Dashboard](DS3.png)**

## Project Workflow

The project follows a simple data analytics workflow:

1. Store and manage the data in PostgreSQL.
2. Use SQL to query and prepare the data.
3. Connect the database to Tableau.
4. Develop interactive visualisations and dashboards.
5. Analyse financial performance across different business dimensions.
